
# Student Data Analysis Using SQL

## About the Project
This project focuses on analyzing student academic performance using SQL. The dataset contains student information such as name, gender, course, branch, age, marks, grades, attendance, and examination results.

SQL queries are used to analyze the dataset and extract meaningful insights.

## Dataset Information
- **Dataset:** Student_Analysis.csv
- **Total Records:** 3000 Students
- **File Format:** CSV
- **Database:** MySQL

### Dataset Columns
- University-ID
- Name
- Gender
- Course
- Branch
- Age
- Marks(%)
- Pass/Fail
- Grade
- Attendance(%)
- Hostel/Day Scholar

## Tools & Technologies
- MySQL
- SQL
- MySQL Workbench
- CSV Dataset

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY

- HAVING
- Aggregate Functions

- RANK()
- ALTER TABLE

## Analysis Performed

1. Find all male and female students.
2. Find students whose age is greater than 20.
3. Find students scoring more than 80%.
4. Find students whose attendance is below 75%.
5. Display passed and failed students.
6. Find the top 5 students based on marks.
7. Count students in each gender category.
8. Find the highest and lowest marks.
9. Calculate average marks for each course.
10. Count students in each branch.
11. Count passed and failed students.
12. Calculate average age for each course.
13. Find courses having more than 100 students.
14. Find branches with average marks greater than 65%.
15. Count passed students in each course.
16. Display the top 10 students according to marks.
17. Find students scoring above average marks.
18. Find students with above-average attendance.
19. Rank students based on marks using RANK().
20. Find the top 3 students in each course using window functions.


## How to Run the Project

**Step 1:** Clone this repository.

```bash
git clone https://github.com/ankit18patel/student-dataset-query.git
```

**Step 2:** Create a database in MySQL.

```sql
CREATE DATABASE newdata;
USE newdata;
```

**Step 3:** Import the CSV dataset into MySQL and create the student table.

**Step 4:** Open the SQL query file in MySQL Workbench.

**Step 5:** Execute the queries to perform student data analysis.
